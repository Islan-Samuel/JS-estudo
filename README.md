# 🎮 JavaScript Lisa_Proof

> Aprendendo JavaScript na prática, transformando conceitos de programação em desafios interativos!

## 📌 Sobre o projeto

Este repositório foi criado com o objetivo de praticar, desenvolver e consolidar conhecimentos em **JavaScript** de uma maneira mais dinâmica e interativa.

A proposta é utilizar um jogo desenvolvido com auxílio de Inteligência Artificial para transformar o aprendizado da linguagem em uma experiência prática, permitindo testar conhecimentos, resolver desafios e compreender melhor a lógica por trás do código.

Mais do que apenas estudar a teoria, a ideia é aprender experimentando, errando, analisando e evoluindo a cada desafio.

## 🎯 Objetivos

- Desenvolver o raciocínio lógico e computacional.
- Praticar a sintaxe e os fundamentos do JavaScript.
- Compreender o funcionamento das estruturas de controle.
- Aprender a trabalhar com operadores lógicos e comparações.
- Entender conversões de tipos e valores booleanos.
- Evoluir progressivamente na resolução de problemas.

## 📚 Conteúdos praticados

Os estudos são direcionados aos fundamentos da linguagem JavaScript, incluindo:

| Conteúdo | Conceitos |
|---|---|
| Variáveis | `let`, `const` e declaração de variáveis |
| Tipos de dados | String, Number, Boolean, Undefined e Null |
| Operadores aritméticos | `+`, `-`, `*`, `/` e `%` |
| Operadores relacionais | `>`, `<`, `>=`, `<=` |
| Operadores lógicos | `&&`, `\|\|` e `!` |
| Estruturas condicionais | `if`, `else` e `else if` |
| Comparações | `==`, `===`, `!=` e `!==` |
| Conversão de tipos | Type Coercion |
| Booleanos | Valores `true` e `false` |

*Os conteúdos podem ser ampliados conforme a evolução dos estudos e dos desafios.*

## 🕹️ Proposta de aprendizado

A metodologia consiste em praticar JavaScript por meio de desafios apresentados pelo jogo.

Durante essa jornada, o objetivo é:

1. Interpretar o problema apresentado.
2. Analisar as condições e regras do código.
3. Identificar o comportamento esperado do JavaScript.
4. Resolver o desafio utilizando os conceitos estudados.
5. Compreender os erros e aprender com eles.

## 💡 Filosofia do projeto

**Aprender programação não é apenas memorizar comandos, mas compreender como o código pensa e como resolver problemas utilizando lógica.**

Este repositório representa minha jornada de aprendizado e evolução com JavaScript, registrando a prática e o desenvolvimento das minhas habilidades na linguagem.

## 🛠️ Tecnologias

- JavaScript (JS)
- Inteligência Artificial (auxílio na criação do jogo)
